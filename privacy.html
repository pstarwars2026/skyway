Privacy, plainly.

The game

The upcoming first-chapter release is planned to have no advertising, purchases or game account. Checkpoints, completion records, sound and effects preferences are stored on your device. There is no cloud save; uninstalling can remove local progress.

The game is not yet released. Advertising experiments in private test builds are being set aside. We will verify the release build and complete its App Store privacy disclosures before launch.

This website

We add no analytics, ads or tracking cookies. Gameplay media is hosted with this page. GitHub Pages may process connection information under the GitHub Privacy Statement.

Support

Support issues are public and handled by GitHub. Do not include private information.
