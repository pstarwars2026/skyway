Privacy, plainly.

This notice covers the public product preview and describes the current private prototype. The game is not yet released. Its final App Store privacy disclosures will be published before launch after reviewing the engine services and purchase integration.

This website

This site does not add analytics scripts, advertising, forms, embedded media services, or tracking cookies. Its screenshot, styling, and graphics are hosted with the page.

The site is hosted by GitHub Pages. GitHub records visitors’ IP addresses for security purposes and processes connection data under its own policies. See GitHub Pages documentation and the GitHub Privacy Statement.

The current prototype

The prototype does not ask you to create a game account. Live advertising is not enabled. We have not added a developer-operated analytics service or cloud save service. Sound and reduced-effects preferences, the opening-level checkpoint, completion, and best deflection count are stored locally on your device. Continuing restores the checkpoint with full health and resets enemies. There is no cross-device save sync; uninstalling the app can remove this local data.

The game uses Unity. Engine and platform services are still being reviewed for the final release; this preview notice is not a claim that the released game has completed its privacy audit.

Planned mobile advertising

We are preparing a free, ad-supported iPhone/iPad release using Unity LevelPlay and Unity Ads. The development project now includes advertising dependencies, but publisher activation and live ad requests are not enabled. Audience settings, privacy choices and real-device behavior are still being validated.

Before release, this notice will describe the actual advertising data practices, service providers, privacy choices and applicable tracking permission. Declining tracking will not prevent gameplay. The native Mac edition is planned to remain ad-free; its final scope is still being evaluated.

Support

Feedback posted in GitHub issues is publicly visible and handled under GitHub’s policies. Share only the minimum information needed to explain the problem. Do not post personal information, purchase receipts, passwords, or private recordings.

Questions and changes

For general questions about this notice, use the public support page without including private information. This notice will be updated when the product’s behavior or available services change.
